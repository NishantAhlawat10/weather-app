# Weather App

A responsive weather application that provides a 7-day weather forecast for searched cities.

### Features
- Search cities with autocomplete suggestions.
- Display daily maximum and minimum temperatures.
- Show weather conditions with icons.
- Display precipitation probability and maximum wind speed.
- Automatically adjust forecast timezone based on the selected location.

### Technologies Used
- HTML
- CSS
- JavaScript
- [Open-Meteo API](https://open-meteo.com/)

### How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run `index.html` using the Live Server extension.
